> 版本: v1.0 · 最后更新: 2026-05-30

## 1. 产品概述

### 1.1 产品定位

**素织手作**是一个面向追求个性与品质消费者的手工帆布包在线定制平台。用户可以在品牌展示页了解定制服务，进入设计工作室后通过可视化配置工具自由搭配面料、皮革、五金和配件，借助 AI 辅助决策，最终完成下单。

### 1.2 核心价值主张

> 从面料到图案，从颜色到配件 — 每一处细节都由你定义。我们用手工工艺，将你的想法变成独一无二的帆布包。

### 1.3 目标用户

| 用户画像 | 描述 |
|----------|------|
| **都市创意工作者** | 插画师、设计师、咖啡馆主理人，追求个性化表达 |
| **品质生活消费者** | 注重材质与工艺，愿意为手工和品质付费 |
| **企业采购方** | 需要定制品牌周边、员工礼品的企业客户 |
| **送礼人群** | 寻找有温度、可定制的礼物 |

## 4. 交互设计规范

### 4.1 视觉风格

| 维度 | 规范 |
|------|------|
| 品牌色 | 深茶色 #2c2416 / 金色 #c4956a / 米色 #faf6f0 |
| 辅助色 | 浅褐 #e8d5c4 / 灰色 #8b7d6b |
| 字体 | 标题: Noto Serif SC / 正文: Inter / 装饰: Playfair Display |
| 圆角 | 大圆角风格 (rounded-2xl / rounded-3xl) |
| 阴影 | 轻阴影 (shadow-sm / shadow-md) |

### 4.2 动画规范

| 场景 | 动画 |
|------|------|
| 页面元素入场 | fade-up (y: 40 → 0, opacity: 0 → 1) |
| 卡片 hover | translateY(-6px) + shadow-lg |
| 图片 hover | scale(1.05) |
| 按钮 hover | 背景色过渡 |
| 画廊滚动 | GSAP 水平固定滚动 |
| 步骤高亮 | 数字圆形背景色切换 |
| FAQ 展开 | max-height + rotate 动画 |

### 4.3 响应式断点

| 断点 | 布局 |
|------|------|
| < 640px | 单列布局，隐藏桌面导航 |
| 640px - 768px | 双列网格 |
| 768px - 1024px | 混合布局 |
| > 1024px | 桌面多列布局 |

## 5. 数据模型

### 5.1 核心实体

```
BagConfiguration {
  canvas: CanvasMaterial    // 帆布面料
  leather: LeatherMaterial  // 皮革材质
  hardware: HardwareMaterial // 五金配件
  size: BagSizeConfig       // 尺寸规格
  monogram: MonogramConfig  // 个性印记
  shoulderStrap: boolean    // 肩带
  keyClasp: boolean         // 钥匙扣
  dustBag: boolean          // 防尘袋
  atmosphere: AtmosphereConfig // 氛围灯光
}
```

### 5.2 本地存储

| Key | 内容 | 用途 |
|-----|------|------|
| canvascraft_inquiries | 咨询表单数据 | 用户咨询记录持久化 |
| my_bag_studio_designs | 设计方案列表 | 作品集持久化 |
